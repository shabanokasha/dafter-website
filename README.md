# موقع دفتر الشُكُك

صفحة تعريفية static لتطبيق دفتر الشُكُك: ملف `index.html` واحد والصور في `assets/`، من غير build.

- **تجربة محلية:** افتح `index.html` في المتصفح.
- **النشر:** GitHub Pages من فرع `main` والفولدر الرئيسي (`/`).
- **رابط Google Play:** لما التطبيق ينزل، دوّر على `قريباً على Google Play` في `index.html` وغيّر الـ `href` لرابط المتجر.
